# ReTerra art

Current item and machine textures are defined in [`scripts/generate_art.py`](../scripts/generate_art.py). Run it with Python and Pillow to regenerate the PNGs and the [art preview](art/pixel-art-preview.png).

The art uses a 16 x 16 grid, solid pixels, light from the upper left and a shared palette: gray stone, worn copper, green plants and blue water. Each machine has front, side and top faces. Off, supplied and working lamps use separate textures. The 128px project icon is enlarged from a 32px drawing with nearest-neighbor sampling.

Keep functional details readable at inventory size. Add new colors only when an existing material cannot convey the difference. Avoid resampling sprites with a smoothing filter.

Models, names and gameplay resources are generated by [`scripts/generate_resources.py`](../scripts/generate_resources.py). No external resource pack is required. Minecraft's own textures are referenced by models where vanilla materials are used; they are not copied into this mod.

The source shapes and current custom artwork use the project's MIT license. Earlier experimental atlases in this directory are retained as development references and are not used by the mod.
