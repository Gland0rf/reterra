# Modrinth images

Upload these four images:

| File | Use | Suggested caption |
| --- | --- | --- |
| `icon.webp` | Project icon | ReTerra |
| `banner.png` | Featured gallery banner or description header | ReTerra |
| `gallery-machines.png` | Gameplay showcase | Restoration machines in action |
| `gallery-heart.png` | Gameplay showcase | Awakening the Heart of the World |

The icon and banner are illustrated promotional artwork made with the built-in imagegen tool. The gallery images are unaltered existing Minecraft captures from the mod's demonstration world. They show the actual machines and effects, rather than natural world generation.

`icon.png` is the full-resolution PNG master. Use the smaller WebP export for the project icon. The upload files are checked in `assets.json`; generation prompts are in `PROMPTS.md`.
